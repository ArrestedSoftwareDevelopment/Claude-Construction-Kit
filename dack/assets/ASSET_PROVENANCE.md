# DACK Asset Provenance

Every external asset must enter the project through this file. Assets without a
verified redistribution license stay in `quarantine/`, which Git ignores. A
quarantined asset may be used to test the local construction workflow, but it
must never be included in a build, export, hub package, or repository commit.

For the current raw-vault audit, candidate-pack summary, and sprite
editor/animator implications, see
`../../docs/DACK-Asset-Audit-and-Sprite-Animator.md`.

## Project-created fallback

The procedural stick figure generated by the DACK prototype is project-created
test art. It is the redistributable default and is deliberately simple enough
to be edited comfortably on the live 32 x 32 sprite pad.
